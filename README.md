# Black Mustache Gents Salon | Web Redesign Concept

Speculative mobile-optimized web application engineered for Black Mustache Gents Salon (JLT, Dubai). Built to modernize the salon's digital presence, eliminate mobile navigation friction, and optimize local service discovery.

Live Demo: https://vanshchokshi.github.io/black-mustache-jvc/

## System Architecture
This platform replaces inefficient web layout structures with a mobile-first responsive frontend. It organizes salon services into an easily accessible pricing matrix and integrates an interactive client review carousel to boost visual trust and local customer conversion.

## Technology & Workflow
Built using HTML5, CSS3, and JavaScript hosted on GitHub Pages. Developed using an AI-assisted rapid prototyping workflow, followed by manual layout adjustments, custom styling, and DOM refactoring.
